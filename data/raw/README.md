# data/raw/

This folder is where you place the downloaded raw datasets before running the pipeline.
It is intentionally empty in the repo (see `.gitignore`) — raw data should not be
committed to git, both for size reasons and because the source datasets have their own
licenses (Kaggle terms of use).

Expected structure once populated:

```
data/raw/
├── events/
│   └── 2019-Nov.csv                       # from Kaggle: mkechinov/ecommerce-events-history-in-cosmetics-shop
├── transactions/
│   ├── olist_orders_dataset.csv           # from Kaggle: olistbr/brazilian-ecommerce
│   ├── olist_order_payments_dataset.csv
│   └── olist_customers_dataset.csv
└── errors/
    └── app_errors_synthetic.csv           # generated by src/transformations.py, not downloaded
```

See the main [README](../../README.md) section 3 for dataset links and
[docs/data_dictionary.md](../../docs/data_dictionary.md) for full column-level lineage.
